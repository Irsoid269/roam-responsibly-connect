# Shikomori (zdj) — statut de traduction

**Non vérifié par un locuteur natif.** Ces traductions sont une tentative de bonne foi, construite à partir d'apparentements avec le swahili (Shikomori et swahili sont deux langues bantoues du groupe sabaki, avec un vocabulaire partagé important, en particulier sur les emprunts d'origine arabe). Elles n'ont pas été validées par une personne comorienne.

À ne pas considérer comme fiable pour une mise en production tant qu'une relecture native n'a pas eu lieu. Seules les chaînes courtes de l'interface (navigation, boutons) sont traduites ici — le contenu des pages reste en français quand le shikomori est sélectionné (`fallbackLng: "fr"` dans `src/i18n.ts`).

Code de langue utilisé : `zdj` (ISO 639-3, Ngazidja / Comorien de Grande Comore) — les autres îles (Anjouan, Mohéli, Mayotte) ont des variantes dont le vocabulaire diffère.
